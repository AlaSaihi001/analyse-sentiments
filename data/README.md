# Données

Le jeu de données **n'est pas inclus** dans ce dépôt (sa licence de redistribution dépend de sa page Kaggle).

1. Télécharger « Text Emotion » (auteur : prajwalnayakat) : https://www.kaggle.com/datasets/prajwalnayakat/text-emotion
2. Placer le fichier CSV dans `data/raw/` sous le nom `final_dataset.csv` (colonnes `text` et `emotion`).
3. Lancer `python code/phase1_pipeline.py` : les fichiers de `data/processed/` sont régénérés.
